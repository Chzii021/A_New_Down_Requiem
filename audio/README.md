# เสียงประกอบเดโม

เกมใช้ไฟล์ `music_custom.mp3` เป็นเพลงประกอบ โดยลดความดังลงอีก 40% และ `spirit_custom.mp3` เป็นเสียงวิญญาณออกจากร่างจากไฟล์ Minecraft Enderman Death Sound Effect.mp3 ที่ผู้ใช้ส่งมา เสียงวิญญาณถูกตัดช่วงเงียบต้นและท้ายให้ดังทันจังหวะ พร้อมคงระดับเสียงเอฟเฟควิญญาณในเกมไว้ เสียงยิงใช้ `gunshot_custom.wav` และเสียงชาวบ้านโดนยิงใช้ `hit_custom.wav` ซึ่งตัดช่วงเงียบต้นไฟล์ MP3 ที่ผู้ใช้ส่งมา เพื่อให้ดังตรงจังหวะที่เกิดเหตุการณ์ เสียงคราฟใช้ `craft_custom.wav` ซึ่งตัดมาเฉพาะเสียงตีทั่งครั้งแรกจากไฟล์ MP3 ที่ผู้ใช้ส่งมา เสียงรีโหลดใช้ `reload_custom.wav` ซึ่งตัดช่วงเงียบต้นไฟล์ MP3 ที่ผู้ใช้ส่งมา แล้วจัดเสียงให้ตรงกับท่ารีโหลด 1 วินาที เสียงไหว้ศาลวนใช้ `End_portal_eye_place1.ogg.mp3`, `End_portal_eye_place2.ogg.mp3` และ `End_portal_eye_place3.ogg.mp3` ตามลำดับ ส่วนเสียงเปิดประตูมิติใช้ `end_portal_activation.mp3` `ambient_original.wav` เป็นเพลงสำรองเมื่อไม่มีไฟล์เพลงที่ผู้ใช้ให้

หากต้องการเปลี่ยนเพลง ให้วางไฟล์เสียงที่มีสิทธิ์ใช้ในโฟลเดอร์นี้แล้วตั้งชื่อ `music_custom.ogg`, `music_custom.wav` หรือ `music_custom.mp3` จากนั้นเปิดโปรเจกต์ใน Godot เพื่อให้โปรแกรมนำเข้าไฟล์ใหม่ แล้วเริ่มเกมอีกครั้ง

ชื่อไฟล์สำหรับเปลี่ยนเสียงอื่นใช้รูปแบบเดียวกัน:

| เหตุการณ์ | ชื่อไฟล์ใหม่ |
| --- | --- |
| เพลงประกอบ | `music_custom.ogg` |
| ยิงปืน | `gunshot_custom.ogg` |
| ยิงโดนชาวบ้าน | `hit_custom.ogg` |
| วิญญาณออกจากร่าง | `spirit_custom.ogg` |
| ประกอบปืนพกสำเร็จ | `craft_custom.ogg` |
| ไหว้ศาลพระภูมิ | `End_portal_eye_place1.ogg.mp3`, `End_portal_eye_place2.ogg.mp3`, `End_portal_eye_place3.ogg.mp3` |
| เปิดประตูมิติ | `end_portal_activation.mp3` |
| รีโหลดกระสุน | `reload_custom.ogg` |

เปลี่ยนสกุลของชื่อไฟล์ในตารางเป็น `.wav` หรือ `.mp3` ได้ เกมจะเลือก `.ogg` ก่อน `.wav` และ `.mp3` ตามลำดับ หากมีหลายไฟล์ชื่อเดียวกันต่างสกุล ให้เหลือเฉพาะไฟล์ที่ต้องการใช้

โปรเจกต์นี้รวมเพลงและเสียงจากไฟล์ที่ผู้ใช้ส่งให้แล้ว หากนำเกมไปเผยแพร่ ควรตรวจสิทธิ์การใช้ไฟล์เสียงที่ผู้ใช้ส่งให้ทั้งหกรายการก่อน
